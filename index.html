Automated AI Task Manager

A two-agent voice AI system: a Vapi voice agent takes a phone call, and an n8n workflow logs the caller, books a session, and emails a personalised AI-written learning plan.

Voice Call (Vapi) Authenticated Webhook Sheets + Calendar Gemini Plan + Email
Data science flow

1. Voice agent: A Vapi agent (speech-to-text, GPT-4.1, text-to-speech) collects the caller's skill, level, weekly hours, time slot and a confirmed email.
2. Tool call: The agent calls a function tool that sends the details to an n8n webhook secured with header authentication.
3. Log and book: A code step unpacks the payload, the caller is logged to Google Sheets, and a 30-minute session is booked on Google Calendar.
4. Fast reply: The workflow replies to Vapi before the slow AI step, so the call never times out.
5. Plan generation: Gemini writes a four-week plan with three free resources as structured JSON, enforced by an output parser.
6. Delivery: A code step builds an HTML email and Gmail sends it. Retries and an error-alert workflow keep it reliable.
Vapi n8n Gemini Webhooks Structured Output Google APIs
